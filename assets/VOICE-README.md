# Canto tradicional integrado

`pregonero-tradicional-v1.m4a` contiene exclusivamente los nombres de las 54 figuras tradicionales. Voz sintética generada con eSpeak NG 1.52.0, español latinoamericano (`es-419`), velocidad 145, tono 43. El índice de segmentos está en `js/voice-cues.js`. La duración total es aproximadamente 82.54 s, con silencios entre nombres; se reproduce únicamente el segmento correspondiente a la figura cantada.

No se incluyen el sintetizador ni sus bibliotecas en la app. Los audios de inicio, última carta y partida terminada proporcionados por el administrador se conservan por separado.
